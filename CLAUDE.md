# CLAUDE.md — Project Context for Claude Code

## Project Overview
This is a portfolio project for **Felipe Pereira da Silva** (GitHub: espartafps), a Capital Markets Analyst with 5+ years at Itaú Unibanco transitioning into consulting/analytics roles. The project demonstrates his analytical depth, financial domain expertise, and ability to build end-to-end data products.

## What This Project Does
Detects anomalous behavior in Brazilian investment funds, correlates anomalies with external market events (USD/BRL, Ibovespa, VIX, interest rates), and uses Claude API to generate natural language insights explaining probable causes and predicting future volatility.

## Tech Stack
- Python 3.12
- Pandas, NumPy — data processing
- Scikit-learn — predictive modeling (Random Forest)
- Plotly — interactive visualizations
- yfinance — Yahoo Finance market data
- python-bcb — Central Bank of Brazil API
- Anthropic API (Claude) — AI-powered insights
- pyarrow — parquet file support

## Known Issues & Fixes Applied
1. **CVM column name change**: Original code used `CNPJ_FUNDO` but CVM now uses `CNPJ_FUNDO_CLASSE`. Already fixed in cvm_collector.py.
2. **2025 historical data**: CVM doesn't serve 2025 as a single historical zip yet (returns 404). The code tries monthly URLs which work for 2026. For 2025 data, the `_build_url` method needs adjustment to also try monthly URLs for the current year - 1.
3. **pyarrow missing**: Not in original requirements.txt. Add with `pip install pyarrow` or add to requirements.txt.

## Data Sources
- **CVM Fund Data**: https://dados.cvm.gov.br/dados/FI/DOC/INF_DIARIO/DADOS/
  - Monthly files: `inf_diario_fi_YYYYMM.zip`
  - Historical files: `HIST/inf_diario_fi_YYYY.zip`
  - Columns: TP_FUNDO_CLASSE, CNPJ_FUNDO_CLASSE, ID_SUBCLASSE, DT_COMPTC, VL_TOTAL, VL_QUOTA, VL_PATRIM_LIQ, CAPTC_DIA, RESG_DIA, NR_COTST
- **Yahoo Finance**: ^BVSP (Ibovespa), BRL=X (USD/BRL), ^VIX, ^GSPC (S&P500), ^TNX (US 10Y)
- **BCB API**: CDI (series 12), SELIC (series 432), IPCA (series 433)

## Claude API Integration
- Model: claude-sonnet-4-20250514
- Used for: anomaly interpretation, executive report generation, predictive alerts
- API key stored in .env file (not committed to git)
